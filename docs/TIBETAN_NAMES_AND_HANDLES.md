# Tibetan and Buddhist Author Handles for PDF Filenames

## Purpose

This document describes the conventions used to create short author handles for a private PDF library.

A typical filename has the form:

    (Brown+Gurung 2017) The Pith Instructions for the Stages of the Practice Sessions
    (Guenther 1984a) Matrix of Mystery
    (Norbu 1980) An Introduction to the Practice of Contemplation
    (Garry 2005) Wisdom Nectar

The bracketed element is the `pdf_id`.

The `pdf_id` is:

- a private retrieval handle;
- the first and most visually prominent part of the filename;
- optimized for recognition, searching, and compactness;
- not intended as an authority record;
- not intended to assert that a Tibetan name element is legally or culturally a surname;
- not intended for public citation.

The governing question is therefore not:

> What is this person's true surname?

It is:

> What is the shortest stable string that reliably makes me think of the correct author?

---

# 1. General principles

## 1.1 Retrieval outranks morphological accuracy

Tibetan names often do not divide into Western-style first names and surnames. A two-part name such as `Tenzin Gyatso` normally consists of two personal-name elements rather than a given name followed by an inherited surname.

The `pdf_id` may nevertheless use one element as a surname-like retrieval handle when that element is:

- distinctive;
- memorable;
- commonly used for alphabetization;
- treated as surname-like in English-language institutions;
- or naturally perceived as the person's identifying element.

Examples:

    Thupten Jinpa       → Jinpa
    Lozang Jamspal      → Jamspal
    Tsering Wangchuk    → Wangchuk
    Tenzin Namdak       → Namdak

This does not claim that Jinpa, Jamspal, Wangchuk, or Namdak is an inherited Tibetan surname.

## 1.2 Functional consistency is more important than morphological consistency

Different handles may derive from different kinds of name elements:

    Gurung              — inherited or ethnic/family surname
    Jinpa               — personal-name element with surname gravity
    Mipham              — distinctive first personal-name element
    Nubchen             — clan-based historical epithet
    Rongzom             — regional or family-style identifier
    Nangzher            — distinctive personal-name element
    Dzogchen Ponlop     — incarnation line and institutional office
    Drikung Chetsang    — lineage plus distinguishing incarnation branch
    Dalai Lama          — institutional title
    Patrul Rinpoche     — conventional title-name compound

These are morphologically inconsistent but functionally consistent: each is a compact recognition handle.

## 1.3 Prefer the shortest sufficient handle

Remove elements that contribute little identifying value.

Examples:

    Mipham Gyatso       → Mipham
    Tenzin Namdak       → Namdak
    Pema Rigtsal        → Rigtsal
    Ngawang Samten      → Samten
    Palden Sherab       → Sherab
    Tsewang Dongyal     → Dongyal

Do not shorten a name merely because shortening is possible. Preserve a compound when it is the familiar mental unit:

    Anam Thubten        → Anam Thubten
    Dzogchen Ponlop     → Dzogchen Ponlop
    Traleg Kyabgon      → Traleg Kyabgon
    Gyalwa Yungdrung    → Gyalwa Yungdrung
    Lishu Takring       → Lishu Takring

## 1.4 Recognition can override title removal

The default rule is to remove generic honorifics and academic titles. An exception is allowed when a title has become an integral part of the person's familiar English-language identity.

Recognized exceptions:

    Dalai Lama
    Patrul Rinpoche

Possible aesthetic exception:

    Thrangu Rinpoche

The systematic handle is `Thrangu`, but `Thrangu Rinpoche` remains acceptable if the bare form feels visually or personally incomplete.

## 1.5 Personal familiarity is legitimate evidence

Because the system is private, lived recognition matters.

For example:

    Anam Thubten → Anam Thubten

Although `Thubten` might be technically sufficient, the compound is preferable because:

- it is how the teacher is actually referred to;
- neither `Anam` nor `Thubten` alone feels natural;
- `Thubten` occurs in several other names;
- the compound has a strong visual fingerprint.

# 2. Titles and honorifics

## 2.1 Normally remove these

The following are normally omitted from the `pdf_id`:

| Element | General function |
|---|---|
| Rinpoche | Devotional honorific, “Precious One” |
| Lama | Teacher or religious master |
| Geshe | Monastic scholarly degree/title |
| Khenpo | Abbot, scholar, or academic title |
| Khenchen | Senior or “great” khenpo |
| Tulku | Recognized reincarnate teacher |
| Lopon / Lopön | Teacher or master |
| Yongdzin | Senior or personal tutor |
| Je | Reverential honorific |
| Lochen | “Great translator” |
| Panchen Lama | Institutional/incarnation title |
| Dalai Lama | Institutional/incarnation title |
| Kyabgon / Kyabgön | “Lord/protector of refuge”; exalted title |

Examples:

    Geshe Sonam Gurung            → Gurung
    Khenpo Yeshe Phuntsok         → Phuntsok
    Khenchen Palden Sherab        → Sherab
    Khenpo Tsewang Dongyal        → Dongyal
    Yongdzin Lopon Tenzin Namdak  → Namdak
    Tulku Pema Rigtsal            → Rigtsal
    Lama Thubten Yeshe            → Thubten Yeshe
    Khenchen Thrangu Rinpoche     → Thrangu

## 2.2 Retain a titled compound when it is the established identity

Some public identities cannot be usefully reduced to a title-free personal name.

Examples:

    Dzogchen Ponlop Rinpoche  → Dzogchen Ponlop
    Traleg Kyabgon Rinpoche   → Traleg Kyabgon
    Patrul Rinpoche           → Patrul Rinpoche
    Dalai Lama Tenzin Gyatso  → Dalai Lama

The retained elements need not be ordinary personal names. Their function is recognition.

## 2.3 Do not retain `Rinpoche` merely to show respect

A filename is not a form of direct address.

Using:

    (Thrangu 2003)

rather than:

    (Thrangu Rinpoche 2003)

is not disrespectful. It is analogous to omitting `Professor`, `Dr.`, or `Venerable` from other retrieval keys.

The death of an author does not require adding or preserving an honorific.

# 3. Lineage, incarnation, clan, and regional elements

## 3.1 Retain them when they discriminate

Lineage and epithet elements may be more useful than the personal-name elements.

Examples:

    Nubchen Sangye Yeshe      → Nubchen
    Rongzom Chokyi Zangpo     → Rongzom
    Chekawa Yeshe Dorje       → Chekawa
    Shardza Tashi Gyaltsen    → Shardza
    Drikung Kyabgon Chetsang  → Drikung Chetsang

These handles retain the element by which the historical figure is most readily recognized.

## 3.2 Remove them when the remaining personal name is more useful

Examples:

    Dakpo Tashi Namgyal        → Tashi Namgyal
    Lhatsun Rinchen Namgyal    → Rinchen Namgyal
    Lochen Dharmashri          → Dharmashri

This decision is not mechanical. A regional or titular element may be retained if it provides stronger recognition.

## 3.3 Historical epithets are not necessarily disposable titles

The following should generally be retained because they are integral to the familiar historical identity:

    Longchenpa
    Tsongkhapa
    Phabongkhapa
    Jigme Lingpa
    Dudjom Lingpa
    Karma Lingpa
    Jigten Sumgon
    Machig Labdron

The fact that an element originated as a title, place designation, clan reference, or descriptive epithet does not mean it should disappear from the handle.

# 4. Surname gravity

## 4.1 Definition

“S​​urname gravity” is the tendency of one name element to function like a surname in English-language contexts even when it is not traditionally an inherited family name.

Evidence may include:

- library catalog inversion;
- academic alphabetization;
- institutional email addresses;
- forms such as “Dr. Jinpa”;
- English-language interviews;
- publisher indexing;
- the author's professional environment;
- the owner's spontaneous recognition habits.

## 4.2 Examples

    Sonam Gurung      → Gurung
    Sangye Khandro    → Khandro
    Lozang Jamspal    → Jamspal
    Thupten Jinpa     → Jinpa
    Tenzin Wangyal    → Wangyal
    Tenzin Namdak     → Namdak
    Namkhai Norbu     → Namkhai Norbu
    Yeshe Phuntsok    → Phuntsok
    Ngawang Samten    → Samten
    Palden Sherab     → Sherab
    Tsewang Dongyal   → Dongyal
    Tsering Wangchuk  → Wangchuk
    Gendun Chopel     → Chopel

## 4.3 Library inversion is evidence, not proof

An authority heading such as:

    Wangyal, Tenzin

does not prove that `Wangyal` is an inherited surname. Library systems must select a filing element even when a naming tradition does not fit Western first-name/surname categories.

It is nevertheless useful evidence for a private retrieval handle.

# 5. Collision management

## 5.1 Do not optimize a handle in isolation

Before shortening a name, search the entire library for potential collisions.

Example:

    Namkhai Norbu
    Thinley Norbu

Using `Norbu` for both would create confusion. Therefore retain:

    Namkhai Norbu
    Thinley Norbu

This is preferable to allowing one author to monopolize `Norbu`.

## 5.2 Expand only as far as necessary

Possible progression:

    Norbu
    Namkhai Norbu
    Chogyal Namkhai Norbu

Use the shortest level that resolves actual collisions.

## 5.3 Conceptual collisions also matter

Even if a string is technically unique, it may trigger the wrong person mentally.

For example:

    Thubten

could suggest:

- Anam Thubten;
- Thubten Yeshe;
- Thupten Jinpa;
- another teacher with `Thubten` as a name element.

Therefore:

    Anam Thubten
    Thubten Yeshe
    Jinpa

are better handles than using `Thubten` indiscriminately.

## 5.4 Distinguish similar incarnation identities with a stable prefix

Examples:

    Gyatrul
    Trungram Gyaltrul

The `Trungram` prefix provides sufficient disambiguation. There is no need to alter the established spelling `Gyaltrul` merely to make it resemble `Gyatrul`.

# 6. Translators, editors, commentators, and source authors

## 6.1 The filename may privilege the modern contributor

A translator may occupy the first position when the translator contributes substantial:

- commentary;
- introductions;
- textual reconstruction;
- notes;
- glossaries;
- interpretive apparatus;
- or editorial organization.

Example:

    (Garry 2005) Wisdom Nectar

This is defensible even though much of the book consists of translated teachings.

## 6.2 Use multiple handles when they improve retrieval

Up to three contributors may be included:

    (Brown+Gurung 2017)
    (Sherab+Dongyal 2016)
    (Brown+Nangzher+Tapihritsa 2022)

The ordering need not reproduce the title-page order. The first position should serve retrieval.

## 6.3 Distinguish publication authorship from traditional attribution

These are different questions:

1. Who is credited on the modern title page?
2. Who translated or edited the publication?
3. To whom is the root text traditionally attributed?
4. Who transmitted the teaching?
5. Who received or wrote down the teaching?
6. Who composed the commentary?

Do not automatically include every lineage figure in the `pdf_id`.

## 6.4 Recommended Bön Dzogchen examples

### The Six Lamps

Recommended:

    (Achard 2017) The Six Lamps

Optional source-credit form:

    (Achard+Tapihritsa 2017) The Six Lamps

The modern publication is presented under Jean-Luc Achard’s name. Tapihritsa is associated with the root instructions transmitted to Nangzher Lodpo.

Do not use:

    (Achard+Nanghzer 2017)

because:

- `Nanghzer` is misspelled;
- the publisher does not present Nangzher as the modern book’s coauthor;
- adding the recipient/redactor without Tapihritsa creates an unclear attribution rule.

If intentionally crediting all traditional participants, define that as a separate policy rather than applying it ad hoc.

### The Twenty-One Nails

Recommended:

    (Brown+Nangzher+Tapihritsa 2022) The Twenty-One Nails

This works because:

- Brown is the modern translator/presenter and an established retrieval handle;
- Nangzher Lodpo supplied the explanatory autocommentary;
- Tapihritsa is associated with the root teachings;
- all three are explicitly associated with the published edition.

Alternative title-page-oriented order:

    (Tapihritsa+Nangzher+Brown 2022)

For this private library, the Brown-first form is preferable.

Correct spellings:

    Nangzher
    Tapihritsa

Avoid:

    Nanghzer
    Taphritsa

# 7. Spelling policy

## 7.1 Do not use Wikipedia as a universal spelling authority

Wikipedia is useful for:

- discovering familiar public forms;
- finding aliases;
- checking broad name recognition;
- identifying titles and offices;
- locating additional sources.

It is not sufficiently consistent to impose a single spelling system across the entire library.

Different articles may follow:

- different publishers;
- different transcription systems;
- different scholarly conventions;
- different periods of English-language usage;
- individual editorial preferences.

## 7.2 Source hierarchy for living teachers and modern authors

Use this order:

1. The author’s own current byline.
2. The author’s official website.
3. The spelling used on the relevant book.
4. The author’s organization or institution.
5. The publisher’s author page.
6. Library authority records.
7. Treasury of Lives.
8. Wikipedia.

The author’s established public spelling normally outranks a theoretically more systematic transcription.

Examples:

    Tenzin Wangyal
    Thupten Jinpa
    Namkhai Norbu
    Tsewang Dongyal
    Sangye Khandro

Do not “correct” these into unfamiliar forms merely to enforce a single transliteration system.

## 7.3 Source hierarchy for historical figures

Use this order:

1. The spelling used by the relevant English publication.
2. The dominant English scholarly or Dharma-literature form.
3. Treasury of Lives for identification and variants.
4. BDRC or Wylie for unambiguous hidden metadata.
5. Wikipedia as a recognition check.

Treasury of Lives is especially valuable for:

- confirming identities;
- distinguishing people with similar names;
- identifying incarnation lines;
- distinguishing offices from names;
- finding dates;
- finding monasteries and institutional relationships;
- recording Tibetan and Wylie forms;
- discovering alternative names.

Its preferred phonetic form does not automatically have to become the filename form.

Examples:

    Treasury-style form     Familiar filename form
    -------------------     ----------------------
    Sanggye                 Sangye
    Gyeltsen                Gyaltsen
    Jikten                  Jigten
    Gonpo                   Gonpo or Sumgon, according to the work
    Lobzang                 Lobsang, if that is the published form

## 7.4 Follow individual bylines rather than global syllable rules

It is acceptable for the library to contain:

    Thubten Yeshe
    Thupten Jinpa

The difference between `Thubten` and `Thupten` need not be normalized if each is the person’s established English byline.

Likewise:

    Gyatrul
    Gyaltrul

may coexist when attached to different established public identities.

## 7.5 Preserve one spelling per person

Once a canonical handle has been chosen, do not alternate between variants for the same author.

For example, select one:

    Phuntsok
    Puntsok
    Phuntsog

Then use that spelling consistently for that person.

## 7.6 Filename spelling and display spelling may differ

The filename can use plain ASCII or reduced diacritics:

    Lodpo
    Sumgon
    Chokyi
    Chonam

A metadata or title field can preserve:

    Lödpo
    Sumgön
    Chökyi
    Chönam

This creates two layers:

- retrieval layer: easy to type and search;
- display layer: typographically and linguistically richer.

## 7.7 Diacritics are optional but should be systematic

Reasons to omit them from `pdf_id`s:

- faster keyboard entry;
- easier cross-platform searching;
- fewer Unicode normalization problems;
- better compatibility across Windows, macOS, Parallels, Total Commander, Finder, and PDF software;
- visual compactness.

Possible policy:

    pdf_id:    Nangzher
    full name: Gyerpung Nangzher Lödpo

    pdf_id:    Jigten Sumgon
    full name: Jigten Sumgön

    pdf_id:    Chokyi Nyima
    full name: Chökyi Nyima Rinpoche

Do not partially normalize a single person across different files.

# 9. Special cases and decisions

## 9.1 Drikung Chetsang

Use:

    Drikung Chetsang

Do not use:

    Drikung Kybgon
    Drikung Kyabgon

Reasons:

- `Kybgon` is a misspelling of `Kyabgon`;
- `Drikung Kyabgon` can refer more broadly to a Drikung incarnation office;
- `Chetsang` distinguishes this branch from Chungtsang;
- the result is shorter and more precise.

## 9.2 Dzogchen Ponlop

Use:

    Dzogchen Ponlop

Do not replace it with the much longer personal religious name. The public incarnation identity has greater retrieval value.

## 9.3 Gyatrul and Trungram Gyaltrul

Use:

    Gyatrul
    Trungram Gyaltrul

Do not normalize both to the same spelling merely for visual consistency.

The `Trungram` prefix already provides disambiguation.

## 9.4 Thrangu

Default:

    Thrangu

Acceptable exception:

    Thrangu Rinpoche

`Thrangu` is systematic, recognizable, and compact. `Thrangu Rinpoche` is permissible if the full compound has become an inseparable visual and emotional identity in the library.

## 9.5 Tsoknyi

Use:

    Tsoknyi

The full personal name is unnecessary because the author consistently presents himself through the Tsoknyi incarnation identity.

## 9.6 Patrul Rinpoche

Use:

    Patrul Rinpoche

Although `Patrul` sometimes appears by itself, the honorific has become deeply integrated into the familiar English-language identity. This follows the same exception rule as `Dalai Lama`.

## 9.7 Namkhai Norbu and Thinley Norbu

Use:

    Namkhai Norbu
    Thinley Norbu

Do not use `Norbu` for either if both are present in the library.

## 9.8 Palden Sherab and Tsewang Dongyal

Use:

    Sherab
    Dongyal

Combined example:

    (Sherab+Dongyal 2016)

This is compact, balanced, and highly recognizable.

## 9.9 Jigten Sumgon

Use:

    Jigten Sumgon

Treasury of Lives may prefer a form such as `Jikten Gonpo Rinchen Pel`, but `Jigten Sumgon` is the established English-language identity in many publications.

Do not replace a familiar, compact handle with a longer authority-record form unless needed for disambiguation.

# 10. Decision procedure for a new author

Apply the following steps in order.

## Step 1: Record the complete byline

Preserve the name exactly as printed on the book or article.

Example:

    Khenchen Thrangu Rinpoche

This belongs in full metadata even if it does not become the handle.

## Step 2: Identify removable generic titles

Remove elements such as:

    Geshe
    Khenpo
    Khenchen
    Lama
    Tulku
    Lopon
    Yongdzin
    Rinpoche

Provisional result:

    Khenchen Thrangu Rinpoche → Thrangu

## Step 3: Identify the strongest recognition element

Ask:

- Which part do I remember first?
- Which part is visually distinctive?
- Which part would I type into Anima?
- Which part retrieves the person rather than many unrelated authors?
- Does an epithet or lineage name work better than the personal name?

Examples:

    Mipham Gyatso          → Mipham
    Rongzom Chokyi Zangpo  → Rongzom
    Nubchen Sangye Yeshe   → Nubchen

## Step 4: Check for surname gravity

Consider:

- academic usage;
- publisher alphabetization;
- interview forms of address;
- institutional email;
- established Western professional usage.

Examples:

    Thupten Jinpa    → Jinpa
    Lozang Jamspal   → Jamspal
    Tsering Wangchuk → Wangchuk

## Step 5: Search the library for collisions

Check both exact and conceptual collisions.

Example:

    Norbu

collides between:

    Namkhai Norbu
    Thinley Norbu

Therefore expand both.

## Step 6: Preserve a familiar compound when shortening feels unnatural

Examples:

    Anam Thubten
    Dzogchen Ponlop
    Traleg Kyabgon
    Gyalwa Yungdrung
    Lishu Takring

## Step 7: Consider the recognition-based title exception

Ask whether dropping the title damages the established identity.

Examples:

    Dalai Lama
    Patrul Rinpoche

Possible personal exception:

    Thrangu Rinpoche

## Step 8: Select the established spelling

For living authors, prefer their own byline.

For historical figures, prefer the relevant publication’s spelling unless a dominant conventional spelling is clearly more useful.

## Step 9: Normalize only for filename usability

Optionally remove diacritics:

    Sumgön → Sumgon
    Lödpo  → Lodpo
    Chökyi → Chokyi

Do not otherwise rewrite the person’s established spelling without a practical reason.

## Step 10: Freeze the handle

Once selected, use the same handle for all works by that person unless a genuine collision later requires expansion.

# 11. Suggested metadata layers

The filename should remain compact, but richer identification can be preserved elsewhere.

Example:

    pdf_id: Brown+Nangzher+Tapihritsa 2022
    filename: (Brown+Nangzher+Tapihritsa 2022) The Twenty-One Nails
    title: The Twenty-One Nails
    modern contributor: Daniel P. Brown
    traditional source: Tapihritsa
    commentator/redactor: Gyerpung Nangzher Lödpo
    spelling variants: Nangzher Lodpo; Nangzher Lopo
    tradition: Bon Dzogchen
    cycle: Zhang Zhung Nyengyu

Historical example:

# 12. Compact policy statement

The entire system can be summarized as follows:

> Select the shortest conventional name element, surname-like element, lineage identifier, historical epithet, office, or familiar title compound that uniquely and immediately evokes the intended author within the library.

Supporting rules:

1. Remove generic honorifics by default.
2. Retain honorifics that have become inseparable from a familiar public identity.
3. Do not pretend Tibetan names have Western surnames.
4. Permit surname gravity for private retrieval.
5. Retain lineage and epithet elements when they discriminate.
6. Prefer recognition over philological normalization.
7. Follow the individual author’s established spelling.
8. Use Treasury of Lives for identification and variants, not automatic filename replacement.
9. Use Wikipedia as a discovery and recognition tool, not a universal spelling authority.
10. Resolve actual library collisions rather than hypothetical ones.
11. Expand a handle only as far as necessary.
12. Preserve familiar compounds when one-element forms feel unnatural.
13. Credit translators and commentators when their contribution drives retrieval.
14. Distinguish modern publication authorship from traditional textual attribution.
15. Keep full authority information in metadata rather than overloading the filename.
